# Расширенный адаптивный кэш — отдельный тестовый вариант

Ничего не публикует и не меняет установленную игру. Основа — последний локальный
кандидат `outputs/cache-capacity-20261114`: штатный Find, отсутствие подготовки
ресурсов и GPU buffer reuse, исправленная миникарта и все остальные изменения.

Потолок общих расчётных квот RAM/VRAM — 3072 МиБ. Бюджеты вычисляются через
64-битные промежуточные значения с учётом свободных виртуальных адресов и RAM.
Резерв адресов — 768 МиБ, физической памяти — 384 МиБ. Один класс ограничен
1792 МиБ. На VIEW раз в секунду проверяется давление памяти; уменьшение квот и
вытеснение выполняются штатным полным пересчётом под штатными блокировками.
Ресурсы не перебираются, принудительно не загружаются, новый пул не создаётся.
Нельзя считать эти квоты фактическим расходом памяти или гарантией от OOM:
учёт ресурсов приблизительный, фрагментация и рабочие ресурсы остаются важны.

Веса: NIF модели/эффекты 40/40, анимации 120/120, обычные текстуры 25/40.
Общий RAM-параметр 80%, VRAM 60%; земля 2048 элементов. Продуктовые policy.c и
обычные сборщики не переключены на этот эксперимент.

Сборка из checkout, с TEMP/TMP и Python bytecode на G:

```
tools/ExpandedCache/build.py native
tools/ExpandedCache/test_native.py
tools/ExpandedCache/build.py helpers
tools/ExpandedCache/verify.py
tools/ExpandedCache/qa_helper.py
tools/ExpandedCache/apply_qa.py
```

У последней команды явный список существующих QA-копий; она сохраняет прежние
байты и атомарно заменяет файлы, не записывая через общие жёсткие ссылки.
Фактические дополнительные операции выравнивания полного overlay/локальных
манифестов отражены в `qa-arcane-full-overlay.json`, `qa-before`, `qa-final.json`.
Никакие RWD и исходные сохранения не заменялись. Не запускать исторические
команды подготовки целых QA-установок поверх этих каталогов.

`live.py` читает/отдаёт команды только игре G:/PawGraphicsQA-20261113/game.
`pressure_test.py` имитирует маленький доступный адресный запас только внутри
этого процесса через временный callback; обязательно восстанавливает его в
finally. Реальная память машины не заполняется. Экспериментальный callback не
входит в обычные EXE. Буфер callback живёт до закрытия QA-процесса, чтобы
исключить гонку исполнения с освобождением кода.

Только итоговые файлы из build-report.json и native/payload являются текущими.
Папки payload-rN — сохранённые промежуточные версии; не устанавливать их.
Первая версия отклонена тестами из-за дефекта spill в TinyCC для сложного
логического выражения; итоговый источник использует отдельные условия, а
правильность ветки проверена в x86-эмуляторе и работающей игре.
