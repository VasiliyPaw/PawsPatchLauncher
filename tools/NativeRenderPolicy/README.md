Сборщик задаёт TEMP/TMP на G: и сохраняет результат в
`outputs/cache-capacity-20261114` относительно основного workspace. Предыдущий
вариант без увеличения кэшей сохранён в `outputs/native-render-policy-20261114`.

он уже содержит опубликованное исправление возвращаемого указателя миникарты.
Предыдущий UI из native-r7 для новой сборки не подходит.

Изменены только подготовка ресурсов, Find, соответствующие диагностические
поля, хеши и адреса новых модулей. `policy.c` сохраняет прежние лимиты 80/100/100,
исправление индивидуальных квот и UI callback. Все прочие встроенные ресурсы
12 вспомогательных EXE сравниваются с опубликованными по SHA-256.
Исторические эксперименты остаются в отдельных исходниках и не включаются
в продуктовые модули.

Проверки исполняют x86-код с тремя базами адресов, исправление квот, отсутствие
загрузок при старом флаге 3, сохранение UI callback, ограничения по свободной
памяти, защиту от повторного входа, установку/откат и контракты миникарты.
Два отдельных Win32 стенда устанавливают UI в искусственные страницы только
своего процесса и проверяют неизменность штатного Find.
Реальный матч и изменение FPS этой сборкой не проверены.
