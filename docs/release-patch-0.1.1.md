# Paw's Patch 0.1.1 — Vanilla / Immortals

## Русский

- Для Vanilla и Immortals добавлено управление камерой на WASD в профиле Dvorak. Стрелки сохраняются, F выбирает союзную метку. Прежняя команда на A освобождена для камеры; остальные позиционные клавиши и клавиши построения сохранены.
- Профиль Dvorak выбирается в настройках самой игры. Патч не переключает профиль автоматически. Исправление одинаково работает с английским и русским текстом, включая режим «Только игровые файлы».
- Сохраняются исправленные значки рот, отображение нуля вместо отрицательного нуля, инициализация параметра рельефа и версия патча в меню. Игровые правила выбранного режима сохраняются.
- Исправления включаются компонентом Paw's Patch отдельно для каждого режима. Нативные исправления требуют поддерживаемого EXE Kohan II 1.3.72; файловые исправления управления и значков доступны независимо от него.

## English

- Vanilla and Immortals gain WASD camera controls in the Dvorak profile. Arrow controls remain available, and F selects the allied marker. The old A action is freed for camera movement; the other positional and formation bindings are retained.
- Select Dvorak in the game's settings. The patch does not switch profiles automatically. The correction works with English or Russian text, including file-only mode.
- Retains corrected company badges, zero display in place of negative zero, terrain-parameter initialization and the patch version in the menu. The selected mode's game rules are preserved.
- Enable the Paw's Patch component separately for each mode. Native fixes require the supported Kohan II 1.3.72 executable; the control and badge data fixes are executable-independent.
