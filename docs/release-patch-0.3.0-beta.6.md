# Paw's Patch 0.3.0-beta.6 — Arcane Wars

## Русский

- Исправлено ещё одно обращение анимации к уничтоженному объекту: проблемная дорожка свечения посоха убрана из 11 анимаций пророка и 11 анимаций Conjuror. Теперь она не используется ни при ожидании, ни при движении, атаке или смерти.
- Модели и текстуры сохранены. Отдельная пульсация свечения посоха отключена; остальные движения, события атак, боевые параметры и сохранения не изменены.
- Исправления графических эффектов и анимации рейнджера из beta.5 сохранены. В локальной проверке игра загрузила исправленные анимации, а ранее падавший бой удалось повторить без вылета. Совместная игра на разных компьютерах остаётся этапом бета-проверки.

Для обновления закройте игру, выберите Arcane Wars → Бета и обновите Paw's Patch до 0.3.0-beta.6. Всем участникам совместной игры рекомендуется обновиться и использовать одинаковые игровые настройки. Обновление лаунчера не требуется.

## English

- Fixed another animation reference to a destroyed object: the problematic staff-glow track has been removed from all 11 Prophet animations and all 11 Conjuror animations, covering idle, movement, combat and death states.
- Models and textures are preserved. The separate staff-glow pulse is disabled; all other movements, attack events, combat values and saves are unchanged.
- The graphics-effect and Ranger animation fixes from beta.5 are retained. A local check confirmed that the game loaded the corrected animations, and the previously crashing battle was replayed without a crash. Multiplayer testing across different computers remains part of the beta evaluation.

Close the game, select Arcane Wars → Beta and update Paw's Patch to 0.3.0-beta.6. All participants should update and use matching gameplay settings. No launcher update is required.
