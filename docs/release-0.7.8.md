# Paw's Launcher 0.7.8

- Нажмите на аватарку в профиле игрока, чтобы открыть компактный просмотр. Закрытие крестиком, Esc или щелчком снаружи возвращает в тот же профиль. Кнопки под фотографией не срабатывают.
- Просмотр использует уже загруженную фотографию; дополнительная загрузка с сервера не нужна.
- Для Vanilla и Immortals доступны отдельные бета-каналы Paw's Patch. Описания компонентов учитывают выбранную версию патча и доступность функций для установленной игры.
- Исправлено определение бета-канала: старый каталог с копией релизного патча больше не принимается за отдельную бету.

Обновления игровых патчей распространяются отдельно: Vanilla и Immortals 0.1.1 добавляют WASD, стрелки и союзную метку F в раскладку Dvorak, а 0.2.0-beta.1 также включает ускоренную штатную передачу сохранений. Arcane Wars 0.3.0-beta.3 обновляет автопостройку и управление ополчением новых городов. Подробности находятся в справке выбранного мода.

---

# English

- Click a player's profile avatar to open a compact preview. Close it with the X, Esc, or an outside click to return to the same profile. Controls behind the image do not receive the click.
- The preview reuses the downloaded photo without an extra server request.
- Vanilla and Immortals have separate Paw's Patch Beta channels. Component descriptions follow the selected patch version and the installed game's feature compatibility.
- Fixed Beta detection: an old catalog containing a copy of a stable patch no longer counts as a distinct Beta.

Game patches update separately: Vanilla and Immortals 0.1.1 add WASD, arrow keys, and the F allied marker to the Dvorak profile; 0.2.0-beta.1 also enables faster native save transfers. Arcane Wars 0.3.0-beta.3 updates construction automation and militia control for new cities. See the selected mod's guide for details.
