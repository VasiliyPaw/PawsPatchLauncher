## Launcher UI fixes / Исправления интерфейса

- История в открытой вкладке теперь автоматически считается прочитанной — также при запуске лаунчера и возвращении в его окно. Непросмотренная вкладка сохраняет свою отметку. Свёрнутое или неактивное окно не снимает отметки в фоне.
- Импорт настроек друга расположен сразу под кодом конфигурации в «Компонентах» и «Мультиплеере».
- Игровые файлы и настройки патча не изменены.

The visible changelog is now marked as read automatically, including on startup and when returning to the launcher. Unopened tabs keep their unread markers; minimized or inactive windows do not clear them in the background. Configuration import now follows the configuration code on both Components and Multiplayer pages.

Validation: 136 automated assertions, configuration/import layout checks on both pages, WPF previews and published-EXE startup checks. Game modules are unchanged.
