# Исправление названия призраков

Исправлено название призываемых призраков Arcane Wars: «Призраки» по-русски, «Привиди» по-украински и «Duchové» по-чешски. Английское название из оригинального мода, немецкое «Erscheinungen» и французское «Apparitions» сохранены. Исправление распространяется через языковые пакеты стабильного и бета-канала, включая режим без функций EXE. Русский текст подключается дополнительным языковым слоем, сохраняя исходную таблицу для проверки совместимости существующих EXE.

Версии Paw’s Patch и лаунчера, игровые параметры и исполняемые файлы не изменены. Локальный эксперимент с камерой в эти пакеты не входит.

---

Corrected the Arcane Wars summoned apparition name in Russian, Ukrainian and Czech. The original English name and existing German/French translations are retained. Updated text archives cover stable/beta channels and the mode without executable features.
