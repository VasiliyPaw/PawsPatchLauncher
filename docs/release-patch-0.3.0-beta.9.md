# Русский

- Исправлен повторный выход защитников из логов, включая логова драконов и штормовых существ. Вернувшиеся живыми защитники могут снова выйти с оставшимся здоровьем; погибшие восстанавливаются полностью перед следующим выходом. Счётчик готовых защитников использует то же правило.
- Исправление работает во всех восьми вариантах EXE беты, при любых сочетаниях расширенных цветов, вражды независимых и игнорирования рассинхронов.
- Обновлены рамки миникарты для людей, гаури, драуга, хароунов, нежити и теней: пустые чёрные промежутки заполнены материалом интерфейса, граница карты стала заметнее. Готовые файлы рассчитаны на 16:9, включая 1920×1080 и 2560×1440. Автоматического выбора по разрешению нет.
- Формат сохранений и владельцы объектов сохранены. После загрузки сейва раненые защитники, уже находящиеся внутри логова, ждут полного восстановления: сейв не хранит признак того, вернулись они живыми или восстанавливаются после смерти. Живые защитники, вернувшиеся в логово после загрузки, используют новое правило.

# English

- Fixed repeat defender deployment from lairs, including dragon and storm-creature lairs. Defenders that return alive can deploy again with their remaining health; killed defenders must fully regenerate before deploying. The ready-defender count follows the same rule.
- The fix is included in all eight Beta EXE variants, across every combination of extended colors, independent hostility and ignore-desync settings.
- Updated minimap frames for Human, Gauri, Drauga, Haroun, Undead and Shadow: race-matching materials fill the empty black gutters and make the map boundary clearer. The supplied files are fitted to 16:9, including 1920×1080 and 2560×1440. There is no automatic resolution selection.
- Save format and saved ownership are preserved. After loading any save, wounded defenders already inside a lair wait for full recovery because saves do not record whether they returned alive or are regenerating after death. Living defenders that return after loading use the new rule.
