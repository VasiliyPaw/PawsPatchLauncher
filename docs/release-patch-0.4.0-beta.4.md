# Paw’s Patch 0.4.0-beta.4 — Arcane Wars

Available in the launcher’s **Beta** channel.

- Fixed host/client differences in builder movement with AI improvements enabled.
- Fixed inconsistent application of bot recruitment limits in multiplayer.

All participants must update before starting a new match. This update does not
resynchronize a match that has already diverged.

The fixes passed compiled host/client regression fixtures and package checks.
A new match on separate computers is still needed to confirm the reported
incident no longer occurs; these fixes do not establish its very first trigger.

## Paw’s Patch 0.4.0-beta.4 — Arcane Wars

Доступно в канале **«Бета»** лаунчера.

- Исправлены различия в движении строителей у хоста и клиентов при включённых улучшениях ботов.
- Исправлено неодинаковое применение ограничений найма ботов в сетевой игре.

Перед новым матчем обновиться нужно всем участникам. Уже рассинхронизированный
матч обновление не восстанавливает.

Исправления прошли автоматические проверки поведения хоста и клиента и проверку
пакетов. Проверка новым матчем на разных компьютерах ещё требуется: точная причина
самого первого расхождения в присланных логах пока не установлена.
