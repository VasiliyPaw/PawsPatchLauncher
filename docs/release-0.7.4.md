# Paw's Launcher 0.7.4

Блок слева внизу теперь называется «Установлено». Он показывает название применённого мода, а на второй строке — Paw's Patch и его версию, если патч включён. Без патча остаётся название мода. Выбор другой вкладки не меняет эту информацию до применения настроек.

Выключение Paw's Patch в Arcane Wars выключает все дополнительные компоненты и делает их недоступными. Карточки затемняются; после включения основного патча компоненты можно выбрать заново. Языки текста и озвучки сохраняются. Правило действует также для старых сохранённых настроек и копируемых конфигураций, чтобы компоненты не запускались без основного патча.

Исправлено мигание подсказки Paw's Team в карточке игрока: обновление присутствия больше не пересоздаёт неизменившуюся плашку роли.

Повторное уведомление теперь только сбрасывает свой таймер на пять секунд и плавно обновляет счётчик ×2, ×3 и далее. Сама плашка не проигрывает анимацию появления заново. Для одиночного уведомления счётчик скрыт; после исчезновения или закрытия отсчёт начинается заново.

# English

The lower-left block is now named Installed. It shows the applied mod name, followed on a second line by Paw's Patch and its version when enabled. Without the patch, only the mod name is shown. Selecting another tab does not change this information until settings are applied.

Turning off Paw's Patch in Arcane Wars disables all additional components and dims their cards. After re-enabling the main patch, components can be selected again. Text and speech languages are preserved. The same rule covers older saved settings and copied configurations, preventing components from running without the main patch.

Fixed the flickering Paw's Team tooltip on player profiles. Presence refreshes no longer recreate an unchanged role badge.

Repeating a notification now only resets its five-second timer and smoothly updates a ×2, ×3 and subsequent repeat counter. The notification card no longer repeats its entrance animation. Single notices have no counter; after a notice expires or is dismissed, the count starts over.
