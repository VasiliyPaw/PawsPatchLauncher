# Paw’s Patch Launcher 0.6.4

- Обновлена вкладка «Друзья»: постоянный компактный поиск и кнопки добавления друга, заявок, рассылки и заблокированных пользователей. Эти действия открываются в отдельных окнах, не заменяя список чатов. В заявках — компактные кнопки принятия и отмены без лишнего меню.
- Чаты с новыми входящими и исходящими сообщениями плавно поднимаются наверх. Перестановка сохраняет открытый диалог и черновик, поддерживает несколько быстрых обновлений подряд и учитывает сообщения после перезапуска лаунчера.
- В рассылке первым открывается «Сейв», затем «Конфигурация». Кнопка «Отправить сейв» в папке игры сразу предлагает выбрать файл, а после успешной отправки всем выбранным друзьям закрывает окно. При частичной ошибке можно повторить оставшиеся отправки. Обычная рассылка из «Друзей» остаётся открытой.
- Регистрация подтверждается шестизначным кодом из письма. После подтверждения лаунчер автоматически входит в аккаунт с учётом галочки «Запомнить меня».
- Окно по умолчанию стало больше — 1600 × 1000, в пределах доступного экрана. При первом запуске этой версии прежний размер сбрасывается один раз; дальнейшие изменения размера снова сохраняются. Монитор и выбранный язык сохраняются.
- В истории изменений первой открывается вкладка «Лаунчер»; для игровых обновлений есть отдельные вкладки Релиза и Беты.
- Исправлена повторяющаяся ошибка журнала при чтении кода завершения игры. Эта правка не является исправлением вылета самой игры.

Обновление лаунчера доступно в обоих каналах. Игровые пакеты Релиза 0.2.0 и Беты 0.3.0-beta.1, настройки компонентов и сохранения не изменены.

---

- Refreshed Friends page with permanent search and separate Add friend, Requests, Broadcast and Blocked dialogs. Requests use compact direct action buttons.
- Conversations move smoothly to the top for new incoming and outgoing messages, retaining the open chat and draft during rapid updates. Order also reflects earlier activity after restarting.
- Broadcast defaults to Save. Game folder / Send save opens the file picker immediately and closes the recipient dialog after all selected deliveries succeed. Partial failures can be retried without resending successes; normal Friends broadcasts remain open.
- Registration uses a six-digit email code and signs in automatically after confirmation, respecting Remember me.
- Larger default window, 1600 × 1000 within the available screen. Legacy window size resets once; later resizing is remembered. Monitor and language preferences are retained.
- Changelog opens on Launcher, with separate Release and Beta history tabs.
- Fixed repeated exit-code logging errors after the game ends; this does not claim to fix game crashes.

Available in both patch channels. Release 0.2.0 and Beta 0.3.0-beta.1 game packages, component settings and saves are unchanged.
