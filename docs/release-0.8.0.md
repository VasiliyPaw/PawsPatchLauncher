# Paw's Launcher 0.8.0

- Расширен архив диагностики: последние журналы игры, дампы и отчёты об ошибках Windows.
- Добавлены чешский, немецкий и французский языки интерфейса и компактный выбор языка.
- Свою карточку и аватарку можно открыть из чата, профиля и подробностей матча.
- Улучшены карточки участников и таймер матча.
- Убрано повторное копирование уже применённой конфигурации друга.
