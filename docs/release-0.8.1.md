# Paw's Launcher 0.8.1

- Добавлены немецкий и французский текст и озвучка игры. Текст и озвучку можно выбирать независимо для Vanilla, Immortals и Arcane Wars.
- Добавлен чешский и украинский текст основной игры, Immortals, Arcane Wars и Paw's Patch в обоих каналах. Немецкий и французский переводы также охватывают дополнения модов и патча. Чешская и украинская озвучка в этот выпуск не входят.
- Добавлен украинский интерфейс лаунчера. Дополнены переводы описаний функций Paw's Patch; названия игровых цветов и дополнительные окна патча используют выбранный язык текста игры.
- Шрифты с чешскими и украинскими символами устанавливаются вместе с соответствующей локализацией. Исправлены ошибки запуска новых языков, пропущенные фразы, названия ИИ и неточные игровые термины; для сверки использованы официальные локализации.
- Для звука уведомлений поддерживаются WAV, MP3, OGG/Vorbis, Opus, FLAC, M4A, AAC, WMA и AIFF. Лаунчер сам преобразует поддерживаемый файл в подходящий формат. Максимальная длительность — 15 секунд, исходный файл — до 20 МиБ.
- Отправленные и полученные сообщения можно выделять мышью и копировать. При наведении на сообщение появляется небольшая кнопка копирования.
- Повторная заявка уже добавленному другу больше не отображается как новая отправленная заявка. Для существующих и входящих заявок показывается их настоящий статус.
- Исправлена возможная ошибка запуска матча из-за сохранённых настроек лобби, несовместимых с выбранной конфигурацией. Перед исправлением сохраняется резервная копия.
- Из истории обновлений убраны повторяющиеся инструкции об обновлении.

Языковые пакеты скачиваются по выбору и сохраняются для повторного использования. Игровой баланс и состав исправлений Arcane Wars 0.3.0-beta.7 сохранены; вместе с локализациями обновлены вспомогательные программы отображения текста. Новые переводы прошли проверки и игровые тесты, но замечания по формулировкам и размещению текста по-прежнему полезны.

# English

- Added German and French game text and speech, selectable independently for Vanilla, Immortals and Arcane Wars.
- Added Czech and Ukrainian text for the base game, Immortals, Arcane Wars and Paw's Patch in both channels. German and French translations also cover mod and patch additions. Czech and Ukrainian speech is not included.
- Added a Ukrainian launcher interface. Expanded translations of Paw's Patch feature descriptions; in-game color names and additional patch windows follow the selected game text language.
- Fonts with Czech and Ukrainian characters are installed with the corresponding localization. Fixed new-language startup errors, missing phrases, AI names and incorrect game terms, using official localizations as references.
- Notification sounds support WAV, MP3, OGG/Vorbis, Opus, FLAC, M4A, AAC, WMA and AIFF. Supported files are converted automatically. The duration limit is 15 seconds and the input size limit is 20 MiB.
- Sent and received messages can be selected with the mouse and copied. A small copy button appears when hovering over a message.
- Sending a request to an existing friend no longer reports a newly sent request. Existing outgoing and incoming requests show their actual status.
- Fixed a possible match-start failure caused by saved lobby settings that are incompatible with the selected configuration. A backup is saved before repair.
- Removed repetitive update instructions from the changelog.

Language packages are downloaded as selected and cached for reuse. Game balance and the Arcane Wars 0.3.0-beta.7 fixes are retained; text-display helpers are updated alongside the localizations. New translations have passed validation and gameplay tests; wording and layout feedback remains welcome.
