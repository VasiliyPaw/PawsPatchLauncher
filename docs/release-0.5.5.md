# Paw's Patch Launcher 0.5.5

## Русский

- Утверждённый новый логотип: буква P с засечками в стиле Palatino Linotype, тонкая золотая окантовка и мягкий синий фон.
- Одинаковое оформление внутри лаунчера, в значке EXE и значке окна; девять размеров иконки от 16 до 256 пикселей.
- При запуске Windows получает уведомление об изменении именно файла лаунчера после обновления. Общий кеш значков и закреплённые ярлыки не изменяются.
- Остальной текст интерфейса остаётся Arial.
- Только обновление лаунчера: игровые пакеты Stable и Beta, настройки и сохранения не изменены.

## English

- Approved new branding: a Palatino Linotype-style serif P, a fine gold rim and a soft blue background.
- Consistent in-app, executable and window icons in nine sizes, from 16 to 256 pixels.
- Startup sends a Windows Shell change notification for this executable after an update. The system-wide icon cache and pinned shortcuts are not modified.
- Other interface text remains Arial.
- Launcher-only release: Stable and Beta game packages, settings and saves are unchanged.
