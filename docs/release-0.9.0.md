# Paw’s Launcher 0.9.0

- Общий чат с каналами EN и RU доступен на всех вкладках. Читать можно без аккаунта, писать — после входа.
- Ширина чата регулируется мышью; выбранный размер и канал сохраняются.
- Добавлены смайлики, упоминания и переход к профилю по аватарке. Нажатие на имя вставляет @упоминание, а сообщения с вашим упоминанием подсвечиваются.
- Уведомления чата: без звука, только упоминания или все сообщения. По умолчанию — только упоминания.
- История изменений открывается отдельным окном с обновлённым оформлением.
- Исправлено копирование конфигурации Arcane Wars с частотой ×2 при выбранном другом моде.

- Community chat with EN and RU channels is available on every page. Guests can read; sign in to write.
- Drag the divider to resize the chat. Your preferred width and channel are remembered.
- Added emoji, mentions and profile cards opened from avatars. Click a name to insert an @mention; messages mentioning you are highlighted.
- Choose silent, mentions-only or all-message chat notifications. Mentions-only is the default.
- Release history opens in a separate, redesigned window.
- Fixed copying an Arcane Wars configuration with ×2 frequency while another mod is selected.
