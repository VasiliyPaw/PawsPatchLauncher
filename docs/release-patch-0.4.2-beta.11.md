# Paw’s Patch 0.4.2-beta.11 — Arcane Wars

Уточнена работа опции «Игнорировать нулевой боевой дух»: при её включении отключается особая обработка истощения, которая оставалась активной в части проверок морали. Боевой дух продолжает уменьшаться и восстанавливаться штатно. Обычное отступление по расовым порогам, ручное отступление и оглушение сохранены. Опция по-прежнему действует только в Arcane Wars при включённом Paw’s Patch и должна совпадать у всех игроков.

Проверки: исходные инструкции обработки морали, восстановление, расовые пороги, установка и откат. Наблюдавшееся ранее длительное зависание после загрузки сейва не воспроизвелось ещё на старой версии; исправление всех подобных зависаний не заявляется.

# Paw’s Patch 0.4.2-beta.11 — Arcane Wars

Completed the “Ignore zero morale” policy: when enabled, the depleted-morale classification is now removed from the remaining morale checks as well. Morale still decreases and recovers normally. Normal routing at racial thresholds, manual retreat and stun are preserved. The option still requires Arcane Wars with Paw’s Patch enabled and must match for every multiplayer participant.

Validation covers native morale classification, recovery, racial thresholds, installation and rollback. The originally reported persistent stall cleared after loading on the previous version; this release does not claim to fix every company stall.
