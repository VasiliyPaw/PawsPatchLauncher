# Paw's Patch 0.3.0-beta.7 — Arcane Wars

## Русский

- Перед входом в сетевое лобби игра дополнительно проверяет версию игры, мод и его версию, Paw's Patch и применённые игровые компоненты. Проверка учитывает содержимое EXE игры и используемого EXE патча, поэтому одинакового номера версии недостаточно при разных файлах.
- При несовместимости окно игры показывает вашу версию игры, Arcane Wars и Paw's Patch, а также версии, необходимые для выбранного лобби. Подключение отклоняется до добавления игрока в лобби.
- Проверка автоматически включена во всех восьми вариантах EXE беты. Язык лаунчера, текста и озвучки не влияет на новую проверку. Обычные проверки файлов игры, пароля и Steam сохранены.
- Все исправления эффектов, рейнджера, пророка и Conjuror из beta.5–beta.6 сохранены. Логика боя, баланс и формат сохранений не изменены.

Всем участникам нужно закрыть игру, выбрать Arcane Wars → Бета, обновить Paw's Patch до 0.3.0-beta.7 и применить одинаковые игровые настройки. Для проверки обязательно запускайте игру через Paw's Launcher. Более старые версии патча несовместимы с лобби новой беты; у старого клиента может отображаться обычное сообщение игры без подробностей. Обновление лаунчера не требуется.

## English

- Before admission to a multiplayer lobby, the game additionally checks the game version, mod and mod version, Paw's Patch version and applied gameplay components. Actual game and active patch EXE hashes are included, so matching version labels alone do not make different executables compatible.
- On mismatch, the game dialog displays your game, Arcane Wars and Paw's Patch versions alongside the versions required by the host. The connection is rejected before the player is admitted to the lobby.
- The check starts automatically in all eight Beta EXE variants. Launcher, text and speech languages do not affect this additional check. The native game-file, password and Steam checks remain enabled.
- All effect, Ranger, Prophet and Conjuror fixes from beta.5–beta.6 are retained. Combat logic, balance and save formats are unchanged.

Every participant must close the game, select Arcane Wars → Beta, update Paw's Patch to 0.3.0-beta.7 and apply matching gameplay settings. Launch through Paw's Launcher to enable the check. Older patch versions cannot join new Beta lobbies; an older client may show the game's usual message without version details. No launcher update is required.
