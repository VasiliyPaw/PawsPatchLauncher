# Paw's Patch 0.3.0-beta.8 — города и цвета

- Выбор цвета стал компактнее и привязан к игроку. Удалён светло-красный, осталось 48 цветов.
- В управлении поселениями убрана кнопка «Правила», настройка ополчения перенесена выше автоулучшения.
- Исправлены приоритеты авторазвития: последнее улучшение центра, цели ресурсов, доход золота, затем прочие постройки.
- Авторазвитие учитывает очередь, прибыльность рынков и запас золота. Рынки улучшаются только по самой выгодной золотой ветке.
- Настройки авторазвития сохраняются отдельно для партии и её сейвов.
- Открытое ополчение применяется к стартовым, новым и захваченным городам и новым зданиям.
- Исправлено изменение владельцев объектов при загрузке сохранения.

# Paw's Patch 0.3.0-beta.8 — cities and colors

- Made the color picker compact and tied colors to players. Removed light red, leaving 48 colors.
- Removed Rules from settlement management and moved the militia setting above city automation.
- Fixed development priorities: final center upgrade, resource targets, gold income, then other buildings.
- Automation accounts for queued work, market profit and the gold reserve. Markets use the most profitable gold upgrade branch.
- Automation preferences are saved separately for each match and its saves.
- Open militia applies to starting, new and captured cities and new buildings.
- Fixed object ownership changing when loading saves.
