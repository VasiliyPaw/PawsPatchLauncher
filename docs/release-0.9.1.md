# Paw’s Launcher 0.9.1

- Аватарки авторов общего чата видны без входа. В карточке игрока гостю предлагается войти в аккаунт.
- В общем чате появился счётчик пользователей онлайн. Он учитывает вошедших пользователей лаунчера.
- Добавлена кнопка копирования сообщений. Убраны лишние пункты и пустые отступы контекстного меню.
- Убрана подсветка имён и аватарок при наведении. Область нажатия на имя ограничена самим текстом.
- Время сообщений общего чата отображается с секундами и выровнено по правому краю.
- Подсветка кнопки профиля стала компактнее. Повторное нажатие возвращает на предыдущую вкладку.

- Community chat avatars are visible without signing in. Guest profile cards offer a Sign in button.
- Community chat now shows how many signed-in launcher users are online.
- Added a message copy button. Removed redundant context-menu actions and empty spacing.
- Removed hover highlights from names and avatars. Name links now cover only the text.
- Community message timestamps include seconds and align to the right.
- The profile button has a more compact highlight. Click it again to return to the previous page.
