# Paw’s Launcher 1.0.10

## Русский

- Открытие профиля больше не закрывает список игроков в сети. После закрытия профиля сохраняются страница и положение списка.
- На аватарках в списке появились круглые индикаторы: **синий — «В сети»**, **зелёный — «Играет»**, как в остальных разделах лаунчера.

## English

- Opening a profile no longer closes the online player directory. Its page and scroll position remain when you close the profile.
- Directory avatars now have round status indicators: **blue for Online**, **green for Playing**, matching the rest of the launcher.
