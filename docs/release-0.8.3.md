# Paw's Launcher 0.8.3

- Карточки игроков в подробностях матча стали на 20% ниже: сохранены аватар, имя и игровые сведения.
- В бете Paw's Patch для Vanilla и Immortals доступны расширенные цвета игроков и игнорирование рассинхронов. Выбор сохраняется отдельно для каждого мода и учитывается при копировании конфигурации друга.
- Выключение Paw's Patch отключает его дополнительные переключатели. При несовместимом EXE доступны только игровые файлы, без функций движка.
- Обновлены подсказки на русском, английском, немецком, французском, чешском и украинском.

# Paw's Launcher 0.8.3

- Match-detail player cards are 20% shorter, retaining avatars, names and game information.
