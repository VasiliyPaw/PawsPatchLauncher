# Paw's Launcher 0.7.2

Исправлена ошибка при переключении на сохранённый старый мод с разными языками текста и озвучки. Например, после Vanilla с русским текстом и английской озвучкой старый Arcane Wars мог показывать ошибку состояния установки и блокировать все действия.

Если выбранные языки или компоненты требуют новых файлов, теперь доступна кнопка «Обновить и применить» с пояснением. Она обновляет выбранный мод и применяет настройки, сохраняя выбранные языки. Это работает для Arcane Wars, Immortals и Vanilla в обоих каналах.

Переключение вкладок само по себе не устанавливает обновления и не меняет файлы игры. При возврате к настройкам, которые поддерживает сохранённый выпуск, снова доступно обычное применение. При отсутствии подходящего обновления или выборе старой версии показывается пояснение вместо ошибки проверки файлов.

Раздельную озвучку можно выбрать и для старого установленного мода, если в каталоге уже доступен поддерживающий её выпуск. Старый каталог обновлений больше не блокирует языки, которые поддерживает сохранённая версия мода.

# English

Fixed an error when switching to a retained older mod with different text and speech languages. For example, switching from Vanilla with Russian text and English speech to an older Arcane Wars release could report an installation-state error and disable every action.

When the selected languages or components need newer files, an explicit Update and apply button now explains and performs the required update. It updates the selected mod and applies the settings while keeping both language choices. This works for Arcane Wars, Immortals and Vanilla in both channels.

Switching tabs does not install updates or change game files. Returning to settings supported by the stored release restores the ordinary Apply action. If no suitable update is known, or an older release is pinned, the launcher explains the limitation instead of reporting a file-verification error.

Separate speech can also be selected for an older installed mod when a supporting release is already available in the catalog. An older update catalog no longer blocks languages supported by a retained mod release.
