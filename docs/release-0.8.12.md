# Paw’s Launcher 0.8.12

- Добавлены настройки беты Paw’s Patch для Vanilla и Immortals: улучшения ботов, выход раненых защитников логов, вражда независимых и странствующие роты. Выбор запоминается отдельно для каждого режима.
- Новые настройки отображаются в подробностях друзей и передаются вместе с конфигурацией.

- Added Paw’s Patch beta options for Vanilla and Immortals: improved bots, wounded lair defenders, independent hostility and roaming companies. Selections are remembered separately for each mode.
- The new options appear in friend details and are included when sharing a configuration.
