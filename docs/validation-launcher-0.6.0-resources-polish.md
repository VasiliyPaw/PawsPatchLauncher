# Ресурсы: порядок и цвета — 0.6.0

Дата: 2026-09-08. Только клиентское оформление и регрессии. Серверные функции, права, ключи, расписание, миграции и публичный выпуск в этой итерации не менялись.

## Изменения

Семь карточек в порядке: база → файлы → письма за день → письма за месяц → вызовы обработчиков за 24 часа → история диалогов → трафик Supabase.

Два недоступных через API счётчика трафика объединены в последнюю компактную карточку с одной кнопкой кабинета. Пустое числовое поле убрано.

«Справочно» и «Лимит справочно» заменены общей нейтральной плашкой «Лимит Free». Её подсказка объясняет, что расход измерен, но лимит взят из тарифа Free без автоматической проверки подписки. Подтверждение тарифа и заполненность больше не смешиваются в одном цвете.

По уточнению пользователя: доля ≤50% зелёная, >50% и ≤75% жёлтая, >75% красная. Дробные значения сравниваются без округления (например, 50,1% уже жёлтый). Устаревшие/недоступные замеры серые; превышение 100% сохраняет настоящий процент, полоса ограничена полной шириной. У счётчика без квоты — нейтральный цвет, без выдуманного процента.

Критерии свежести сохранены: отметка успешного замера должна быть не старше 30 минут и не более чем на две минуты в будущем относительно часов ПК. Дневные/месячные письма также проверяют конец периода по UTC. Ошибка нового опроса показывается отдельно, даже если сохранённый предыдущий замер ещё недавний. Сервер опрашивает раз в 15 минут; клиент пересчитывает состояние при отрисовке после открытия/обновления вкладки, отдельного непрерывного таймера для уже открытой вкладки нет.
