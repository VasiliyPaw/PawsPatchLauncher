# Paw’s Patch Launcher 0.6.1

- Панель «Администрирование» закреплена: заголовок, вкладки, кнопка «Обновить», поиск и время проверки остаются видимыми при прокрутке.
- Прокручивается только содержимое выбранной вкладки. Переключение из конца длинного списка открывает следующую вкладку сверху; плавная прокрутка и анимация перехода сохранены.
- Изменение одинаково работает в «Статусе», «Ресурсах», «Пользователях», «Блокировках» и «Удалённых», на русском и английском языках.

Игровые файлы, настройки, серверные обработчики и правила доступа не изменились. Обновление лаунчера доступно в обоих каналах патча.
