### Совместимость ×2

Клиентские проверки охватывают 768 сочетаний двух каналов, трёх частот Standard/×2/×4 и семи двоичных параметров. Для ×2 выбирается ровно один совместный профиль: с новыми блуждающими ротами либо без них. Проверяются также код конфигурации, определение изменений, возврат настройки, кэш и сохранение состояния.

Повторно прошли семь установочных переходов между Standard/×2/×4 с проверкой реальных файлов и состояния в одноразовом каталоге. Все сочетания непосредственно в игре не проигрывались. Для старого закреплённого выпуска без соответствующих пакетов режим ×2 недоступен.

## Серверная проверка и границы

Четыре ранее замеченных 503 в просмотренных журналах относятся к `social-transfers?action=cleanup`, старому deployment v1. Действует v6 с обработкой пустого успешного ответа `paw_transfer_cleaned`; повторные тесты передачи сейвов — 24/24 PASS, мониторинга — 121 PASS. В просмотренном суточном окне более поздних 5xx нет. Точные времена и границы причинного вывода записаны в [финальном аудите](release-audit-final-0.6.0.md). Новых серверных публикаций, изменений прав, аккаунтов и секретов при выпуске не выполнялось.

EXE не имеет Authenticode-подписи издателя. Подписанные ленты не заменяют её. Сохраняются границы аудита: не проверены все DPI/антивирусы/чистые Windows, не запускалась новая игровая сессия или реальные модерационные действия.

Старый обновлятор 0.5.8 может откатить обновление при слишком длинном пути: закрыть лаунчер и однократно заменить только EXE официальным файлом. Игра, настройки и сейвы сохраняются. Инструкция включена в описание выпуска. Тестовая сборка уже с номером 0.6.0 может не предложить автоматическую замену другой сборкой с тем же номером; для точного публичного файла используется загрузка из официального выпуска.

Локальные доказательства: `release_workspace_060/publication/published`, `feed-final`, `actual-release-update`, `x2-install`. Прежние сборки пользователя и VM не перезаписывались и не перезапускались.
