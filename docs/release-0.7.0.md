# Paw's Launcher 0.7.0 — моды, установка и чаты

- Добавлен выбор Vanilla, Immortals и Arcane Wars с отдельными каналами обновлений.
- Скачанные моды можно переключать без повторной загрузки.
- Текст и озвучка игры выбираются независимо. Исправлены русские шрифты и дополнен перевод Immortals.
- Добавлено отдельное окно обновления лаунчера с прогрессом и скоростью загрузки.
- Обновлены интерфейс, уведомления и история изменений с фильтрами.
- Улучшены чаты, смайлики, список друзей и копирование конфигурации.
- Исправлены восстановление входа и работа без соединения.
- Расширен архив диагностики.

# Paw's Launcher 0.7.0 — mods, installations and chat

- Added Vanilla, Immortals and Arcane Wars selection with separate update channels.
- Downloaded mods can be switched without downloading them again.
- Game text and voices can be selected independently. Fixed Russian fonts and expanded the Immortals translation.
- Added a dedicated launcher updater with download progress and speed.
- Updated the interface, notifications and filterable change history.
- Improved chats, emoticons, friends and configuration copying.
- Fixed sign-in recovery and offline behavior.
- Expanded diagnostic archives.
