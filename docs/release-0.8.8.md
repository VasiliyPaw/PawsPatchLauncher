# Paw’s Launcher 0.8.8

- Game settings are available in Components through the gear button next to the channel selector.
- Before launching, choose a 16:9 resolution up to 4K, FPS limit, audio volume, match timer and minimap colors.
- These settings stay on this computer and are not included when copying configurations. A backup is created when saving.
