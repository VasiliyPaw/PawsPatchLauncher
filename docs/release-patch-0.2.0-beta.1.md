# Paw's Patch 0.2.0-beta.1 — Vanilla / Immortals

## Русский

- Первый отдельный Beta-канал Paw's Patch для Vanilla и Immortals. Включает исправления 0.1.1: значки рот, отображение нуля, инициализацию рельефа, версию в меню и управление WASD со стрелками и союзной меткой F в профиле Dvorak.
- В Paw's Patch встроен прежний проверенный R2 для ускорения штатной передачи сохранения участникам сетевого лобби. Отдельного переключателя нет; дружба и ручное принятие файла в лаунчере не требуются.
- Настройка R2 сохранена: файловый бюджет 1200 байт и до 16 пакетов участнику за проход отправки. Формат сохранения, размер блоков, подтверждения, повторы и штатные ограничения полосы передачи остаются прежними. Нативные инструкции и защитные проверки совпадают с ранее выбранным R2; новой скорости WAN эта версия не обещает.
- Нужен поддерживаемый EXE Kohan II 1.3.72. При выключенном Paw's Patch и в режиме «Только игровые файлы» передача остаётся обычной. Для сетевой игры используйте совместимую бету у всех участников и одинаковые игровые настройки.
- Beta для этих двух режимов добавляет к базовым исправлениям только R2. Баланс, карты, палитра и автоматизация городов Arcane Wars в неё не входят.

## English

- The first separate Paw's Patch Beta channel for Vanilla and Immortals. Includes the 0.1.1 fixes: company badges, zero display, terrain initialization, menu version labels and Dvorak WASD controls with arrows and the F allied marker.
- The previously verified R2 tuning is built into Paw's Patch to speed up the game's native lobby save transfer. There is no separate toggle, and launcher friendship or manual file acceptance is not required.
- R2 retains its 1200-byte file-stage budget and at most 16 packets per participant per send pass. Save format, block sizes, acknowledgements, retries and native bandwidth limits remain unchanged. Native instructions and guards match the previously selected R2; this version promises no new WAN speed result.
- Requires the supported Kohan II 1.3.72 executable. Disabling Paw's Patch or using file-only mode retains stock transfer. Multiplayer participants should use a compatible Beta and matching gameplay settings.
- For these two modes, Beta adds only R2 to the base fixes. Arcane Wars balance, maps, palettes and city automation are not included.
