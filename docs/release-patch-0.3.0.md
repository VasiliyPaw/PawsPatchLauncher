# Paw's Patch 0.3.0 — релиз Arcane Wars

- Автоулучшение городов с целями по ресурсам, запасом золота и сохранением настроек партии.
- Настройка открытого ополчения для стартовых, новых и захваченных городов и новых зданий.
- Быстрая передача сейвов и проверка совместимости перед входом в лобби.
- Компактный выбор 48 цветов с привязкой к игроку.
- Исправления вылетов и анимаций пророка.

- Обновлены рамки миникарты всех шести рас.
- Исправлены Powers и Shards, переводы, подсказки и владельцы объектов в сейвах.

# Paw's Patch 0.3.0 — Arcane Wars release

- City automation with resource targets, a gold reserve and saved match preferences.
- Open-militia settings for starting, new and captured cities and new buildings.
- Faster save transfers and compatibility checks before joining a lobby.
- A compact 48-color picker with colors tied to players.
- Crash fixes and corrected Prophet animations.
- Wounded lair defenders can fight again; killed defenders wait to recover.
- Updated minimap frames for all six races.
- Fixed Powers and Shards, translations, tooltips and saved object ownership.
