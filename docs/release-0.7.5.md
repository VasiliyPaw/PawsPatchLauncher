# Paw's Launcher 0.7.5 — команды и подробный статус игры

- Выбранные компоненты Arcane Wars восстанавливаются после повторного включения Paw’s Patch.
- Добавлен подробный статус игры: меню, лобби, матч или редактор.
- В подробностях показываются команды, участники, игровые цвета, время матча и размер карты.
- Подробный статус можно отключить в настройках.
- Уточнена подсказка Paw’s Team.

# Paw's Launcher 0.7.5 — teams and detailed game activity

- Selected Arcane Wars components are restored when Paw’s Patch is enabled again.
- Added detailed game status: menu, lobby, match or editor.
- Details show teams, participants, player colors, match time and map size.
- Detailed status sharing can be disabled in Settings.
- Updated the Paw’s Team tooltip.
