# Paw’s Patch 0.4.0-beta.1

- Добавлен переключатель улучшений ботов, включённый по умолчанию: оценка найма и лимитов, расширение и восстановление застрявших истощённых рот.
- В лобби хоста появился общий выбор расы, фракции и сложности для текущих и новых ботов.
- При выборе союзного объекта показывается экономика его королевства.
- Королевства корректно показывают восемь зданий; подписи и отступы выровнены.
- Очки королевства показываются с дробной частью. Разрушитель «Водоворот» расходует 0,75 очка при включённом балансе осадных машин.
- Безобидные птицы и рыбы скрыты с миникарты, дальность реакции ополчения анклава слаан увеличена.
- Расширена запись сведений о вылетах.

# Paw’s Patch 0.4.0-beta.1

- Added AI improvements, enabled by default: recruitment and capacity evaluation, expansion, and recovery of stuck exhausted companies.
- Hosts can set the race, faction and difficulty for all current and new bots in the lobby.
- Selecting an allied object displays its kingdom’s economy.
- Kingdoms correctly display eight buildings; labels and spacing are aligned.
- Kingdom points display fractional values. The Maelstrom Destroyer costs 0.75 points with siege engine balance enabled.
- Harmless birds and fish are hidden from the minimap; Slaanri enclave militia react at a greater distance.
- Expanded crash diagnostics.
