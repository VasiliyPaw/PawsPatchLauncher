# Проверка первого языка и объединённого обновления 0.6.2

2026-09-08. Дополнение пользователя поступило после отправки immutable-тега 0.6.1. Его файлы/тег не заменяются. Обычные ленты остаются на 0.6.0 до проверки 0.6.2, затем переключаются сразу на объединённую версию.

- `UserSettings.Language` по умолчанию — `en`.
- `SettingsStore.Load()` не выбирает язык по Windows при отсутствии настроек; сохранённый файл читается как прежде.
- Добавлен изолируемый каталог `SettingsStore` для тестов, стандартный путь пользовательских настроек не изменён.
- Игровая русская локализация, канал, частота рот и остальные игровые настройки не менялись.

- Основной набор: **8635 PASS**, включая **29 новых проверок языка**.

- Регрессия закреплённой админ-панели в 0.6.2: **148 PASS RU**. Оба языка и оба размера полностью проверены также в исходной правке [0.6.1](validation-launcher-0.6.1.md).
