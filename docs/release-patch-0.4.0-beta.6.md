# Paw’s Patch 0.4.0-beta.6

## Русский

- Исправлена ошибка улучшенных ботов, которая могла вызвать рассинхронизацию уже в начале матча.
- Исправлен связанный с ней случай аномально большого предупреждения о времени работы ИИ.

Перед новым сетевым матчем всем участникам нужно обновиться до одной версии.
Расширенные журналы первого рассинхрона продолжают сохраняться.

## English

- Fixed an improved-AI error that could cause desynchronization at the start of a match.
- Fixed the related case of an abnormally large AI time-limit warning.

All players must update to the same version before starting a new multiplayer match.
Extended diagnostics for the first desync remain enabled.
