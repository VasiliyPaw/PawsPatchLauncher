# Paw's Launcher 0.8.2

- Открытый список выбора или контекстное меню больше не позволяет прокручивать страницу под ним. Исправлено в том числе для выбора языка интерфейса; длинные списки продолжают прокручиваться внутри.
- Выделение отправленных сообщений снимается при переходе к другому сообщению или клике вне текста. Несколько сообщений больше не остаются выделенными одновременно; убрано выделение пустого места после текста. Копирование выделенного текста и кнопка копирования сохранены.
- Для недоступных вложений Discord с истёкшей ссылкой показывается понятное объяснение. Рабочие ссылки и уже загруженные изображения продолжают отображаться; остальные ошибки можно повторить.
- Исправлено повторное открытие карточки игрока во время её закрытия.
- Количество цветов в описании компонента берётся из выбранного канала: новая бета Arcane Wars показывает 48 цветов.

# English

- Open dropdowns and context menus now block scrolling of the page underneath, including the interface-language selector. Long lists still scroll internally.
- Sent-message selection clears when selecting another message or clicking outside the text. Multiple messages no longer retain selection at once, and trailing blank space is no longer highlighted. Text selection and the copy button remain available.
- Unavailable Discord attachments with expired links now show a clear explanation. Working links and cached images remain usable; other failures can still be retried.
- Fixed reopening a player card while its closing animation was still running.
- Color descriptions follow the selected channel: the new Arcane Wars Beta shows 48 colors.
