Paw’s Launcher 1.0.13 — озвучка фракций

- Добавлен отдельный выбор языка озвучки для каждой фракции.
- Набор озвучки сохраняется при переключении на обычный режим.
- Упрощено копирование игровых настроек из профиля игрока.

Paw’s Launcher 1.0.13 — faction speech

- Added a separate speech language choice for each faction.
- Your faction speech setup is kept when switching to regular speech.
- Simplified copying game settings from a player’s profile.

Paw’s Launcher 1.0.13 — Fraktionssprachausgabe

- Für jede Fraktion lässt sich eine eigene Sprache der Sprachausgabe wählen.
- Die Fraktionsauswahl bleibt beim Wechsel zur normalen Sprachausgabe gespeichert.
- Spieleinstellungen lassen sich einfacher aus einem Spielerprofil übernehmen.

Paw’s Launcher 1.0.13 — voix des factions

- Ajout du choix d’une langue de voix pour chaque faction.
- Les choix des factions sont conservés lors du retour aux voix normales.
- Copie des paramètres de jeu depuis le profil d’un joueur simplifiée.

Paw’s Launcher 1.0.13 — dabing frakcí

- Pro každou frakci lze vybrat samostatný jazyk dabingu.
- Výběr dabingu frakcí zůstává uložen při přepnutí na běžný dabing.
- Zjednodušeno kopírování herních nastavení z profilu hráče.

Paw’s Launcher 1.0.13 — озвучення фракцій

- Додано окремий вибір мови озвучення для кожної фракції.
- Набір озвучення зберігається при перемиканні на звичайний режим.
- Спрощено копіювання ігрових налаштувань із профілю гравця.
