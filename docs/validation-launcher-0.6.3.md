# Плавный прогресс — проверка 0.6.3

2026-09-08. Пользователь разрешил публикацию через обычное автообновление. Номер 0.6.2 зарезервирован отменённой попыткой изменения первого языка; правила выбора языка остаются прежними.

## Изменение

Общая полоса `OperationProgress` использует анимацию WPF длительностью 220 мс с плавным замедлением. Новое показание начинает движение от текущего видимого значения, а отдельная цель хранит реальный измеренный процент. Повторное показание не перезапускает анимацию. Полоса не уходит выше последней цели и не прогнозирует отсутствующие байты; текст объёма/скорости/остатка остаётся реальным.

Сброс файла или повторная попытка применяются сразу. Переход к установке без известного процента останавливает числовую анимацию и включает прежний непрерывный индикатор. Завершение, отмена, скрытие, выгрузка элемента и закрытие окна освобождают анимацию. Защита от отложенных событий `Progress<T>` сохранена. Сетевые запросы, загрузчик, проверка подписей и установка файлов не менялись.

Первый тест повторного показания обнаружил мгновенное изменение базового значения до первого кадра WPF. Исправлено: до первого кадра база сохраняет текущую видимую позицию, цель хранится отдельно. Итоговый набор проверяет это повторно.
