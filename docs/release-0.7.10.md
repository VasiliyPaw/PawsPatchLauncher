# Paw's Launcher 0.7.10

- В сведениях об участниках лобби и матча «Подраса» переименована во «Фракцию»; в английском интерфейсе используется Faction.
- В блоке «Установлено» рядом с названием всегда показывается версия установленного мода: например, Immortals 2.1 или Arcane Wars 0.82.1.8. Для Vanilla показывается фактическая версия игры.
- Если Paw's Patch применён, его название и версия отображаются отдельной строкой под модом. При выключенном патче остаётся строка мода с версией. Выбор другого режима без применения настроек не меняет сведения об установленном моде.

Переустанавливать моды или игровой патч не требуется.

---

# English

- Renamed Subrace to Faction in lobby and match participant details, including Russian labels and tooltips.
- Installed now shows the installed mod name and version, such as Immortals 2.1 or Arcane Wars 0.82.1.8. Vanilla displays the actual game version.
- When applied, Paw's Patch and its version appear on a separate line below the mod. Turning the patch off leaves the mod and its version visible. Selecting another mode without applying settings does not change the installed information.

Reinstalling mods or the game patch is not required.
