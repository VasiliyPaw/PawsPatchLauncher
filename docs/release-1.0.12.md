# Paw’s Launcher 1.0.12

## Русский

- Загрузку можно поставить на паузу, остановить и продолжить после перезапуска. Добавлено ограничение скорости.
- После ошибки установки показываются понятное объяснение и действия для продолжения.
- Из профиля игрока можно открыть сравнение игровых настроек. Язык текста и озвучки не считается различием для совместной игры.
- В профиле аккаунта можно отдельно выбрать видимость настроек и подробной активности: всем, друзьям или никому.
- Настройки видимости загружаются автоматически и сохраняются кнопкой «Сохранить». Если игрок скрыл данные, об этом написано в его профиле.
- Уменьшена нагрузка на интерфейс при загрузке файлов и отображении аватарок.

## English

- Downloads can be paused, stopped and resumed after restarting. Added a speed limit.
- Installation errors now show a clear explanation and actions to continue.
- Player profiles offer a gameplay settings comparison. Text and speech languages are excluded from multiplayer differences.
- Your account profile lets you separately share settings and detailed activity with everyone, friends only or nobody.
- Visibility settings load automatically and use a single Save button. Profiles explain when a player has hidden data.
- Reduced interface work during file downloads and avatar loading.
