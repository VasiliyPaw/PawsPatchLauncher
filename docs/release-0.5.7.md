# Paw's Patch Launcher 0.5.7

- «О патче» обновляется вместе с подписанным описанием выбранного выпуска. Новые тексты не требуют обновления EXE лаунчера. Полученная справка доступна после перезапуска без интернета; закреплённые старые версии используют свою справку.
- Описание дополнено случайной картой, случайным временем суток, исправлением стартового рассинхрона и правилами цветов в сетевом лобби и сохранениях.
- В бете 7 расширенные цвета можно включать вместе с пропуском рассинхрона. Сочетание сохраняется и передаётся кодом конфигурации. Старые беты без нужного файла запуска не предлагают это сочетание.

Для новых игровых функций обновите и бету патча на всех компьютерах. Пропуск рассинхрона не исправляет расхождения и пропускает в том числе серьёзные ошибки.

## English

- About the patch is delivered in the selected release's signed feed and remains available offline after restarting. Text updates no longer require a launcher EXE update. Pinned old releases retain their own guide.
- Updated documentation covers random map type and time of day, the startup desync fix, and multiplayer/saved-game color behavior.
- Beta 7 supports extended colors with desync bypass, including saved settings and friend-code import. Older Betas lacking the combined helper keep their compatibility restriction.

Update the patch Beta on every multiplayer computer. Bypass does not repair divergent game states and also skips serious desyncs.
