# Paw's Patch 0.3.0 — Vanilla / Immortals (ru)

- Возможности беты Vanilla и Immortals теперь доступны в релизе.
- 39 цветов игроков с компактным выбором в лобби.
- Исправлены чёрные промежутки возле миникарты для всех шести рас.
- При включённом пропуске рассинхронов сохраняется диагностический журнал первой ошибки в матче.
