# Paw's Launcher 0.7.1

Исправлено исчезновение Paw's Patch и кнопки «Установить» у ваниллы после обновления со старого лаунчера. Пустая запись, созданная из старого каталога Arcane Wars, больше не считается установленным выпуском ваниллы и не скрывает новые компоненты и локализацию.

Исправление действует и для уже затронутых установок 0.7.0: после обновления доступна обычная установка компонентов ваниллы. Сохранённые выпуски других модов и применённые настройки игры сохраняются.

Название Vanilla теперь отображается на английском при любом языке лаунчера, включая выбор мода, справку и карточки игроков.

---

# English

Fixed missing Paw's Patch components and the Install button for Vanilla after upgrading an older launcher. An empty entry adopted from an old Arcane Wars catalog no longer counts as an installed Vanilla release or hides its new components and language packages.

Existing affected 0.7.0 installations recover automatically after updating. Retained releases of other mods and applied game settings are preserved.

The Vanilla name now stays in English in every launcher language, including mod selection, the guide and player cards.
