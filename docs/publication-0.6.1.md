- Новый помощник: **реальный переход 0.6.0 → 0.6.1 PASS** на изолированном глубоком Unicode-пути, сохранение предыдущего EXE и подтверждение готового окна. Не выполнялся интерактивный переход в установленном пользователем экземпляре.

- Обе финальные ленты: валидные подписи, 15 пакетов; весь набор игровых данных, совместимости и сохранённых выпусков сохранён без изменений. Меняются только лаунчер, дата публикации и история лаунчера.
- После отправки коммита лент выполняется отдельное чтение публичных Stable/Beta и скачивание объявленного ими EXE.

Первый smoke-прогон встретил старый лог с ошибкой искусственного сетевого теста: каталог был назван по PID, который Windows выдала повторно. Лог имел время 16:51:18 UTC, новое окно подтвердилось в 16:58:44 UTC. Инструмент теперь проверяет свежесть маркера и лога относительно времени старта текущего процесса; старые доказательства не удалялись. Исправление относится только к инструменту проверки, не к опубликованному EXE.
