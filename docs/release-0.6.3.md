# Paw’s Patch Launcher 0.6.3

- Плавное заполнение полосы загрузки при обновлении лаунчера и при скачивании пакетов для установки или обновления патча.
- Новые показания плавно продолжают движение от текущего положения. Размер загрузки, скорость и оставшееся время по-прежнему основаны на реальных данных.
- При смене файла, повторной попытке или отмене полоса корректно сбрасывается; события завершённой загрузки не затрагивают следующую операцию. На этапе установки без точного процента сохраняется непрерывный индикатор.
- При отключённых анимациях Windows прогресс обновляется сразу, без анимации.

Игровые файлы, настройки компонентов и выбор языка не изменились. Обновление доступно в обоих каналах патча.

Скачивание этой версии старым лаунчером ещё использует прежнюю полосу; плавность действует после установки 0.6.3.
