# Paw's Launcher 0.7.6

Исправлено определение подробного статуса игры при запуске через помощники патча.
Служебный или завершающийся процесс больше не мешает лаунчеру найти саму игру.

В обновление входят нововведения 0.7.5: список участников по командам с игровыми
цветами, отдельная иконка бота, подробности лобби и матча и сохранение выбранных
компонентов при отключении Paw's Patch. Случайный цвет показывается серым маркером,
пока игра не назначит его при старте матча. Серверная поддержка включена.

---

# English

Fixed detailed game activity detection when starting through patch helpers.
A helper or exiting Steam bootstrap no longer prevents the launcher from finding
the native game process.

Includes the 0.7.5 changes: participants grouped by team with in-game colors,
a dedicated bot icon, lobby/match details, and remembered optional components
when Paw's Patch is disabled. Random colors use a neutral marker until the game
assigns them at match start. Backend support is enabled.
