# Paw’s Patch 0.4.0-beta.5

При включённом пропуске рассинхрона теперь сохраняется подробный журнал первой ошибки в матче. Повторные ошибки не создают дубли; в новом матче или после загрузки сохранения запись снова доступна. Журналы автоматически попадают в архив диагностики лаунчера.

---

Continuing after a desync now preserves a detailed log of the first error in a match. Repeated errors do not create duplicate logs; a new match or loaded save enables another capture. The launcher includes these logs in diagnostic archives automatically.
