# Paw’s Patch Launcher 0.6.2

- При первом запуске интерфейс открывается на английском независимо от языка Windows. После переключения выбранный язык сохраняется; существующий русский или английский выбор не сбрасывается.
- Панель «Администрирование» закреплена: заголовок, вкладки, кнопка «Обновить», поиск и время проверки остаются видимыми. Прокручивается только содержимое выбранной вкладки.
- Из конца длинного списка можно сразу переключить вкладку; новая вкладка открывается сверху. Плавность прокрутки и переходов сохранена.

Игровые файлы, локализация самой игры, настройки компонентов и сервер не изменились. Обновление доступно в обоих каналах патча.
