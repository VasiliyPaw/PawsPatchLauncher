# Paw's Launcher 0.7.11

- Обводка аватарки при наведении больше не перекрывает кружок статуса. После закрытия просмотра аватарки обводка исчезает, если курсор находится в другом месте. Для навигации клавиатурой сохранён отдельный указатель фокуса.
- Подсказки Paw's Patch для Vanilla и Immortals обновляются при смене мода и канала. Они используют описание выбранного выпуска, даже если локально сохранён более старый пакет. При явном выборе архивного выпуска показываются его возможности.
- В актуальных релизном и бета-каналах указаны камера на WASD и стрелках и союзная метка на F в профиле Dvorak. В бета-каналах также указана быстрая передача сохранений участникам сетевого лобби. При несовместимой версии игры эта функция отмечается как недоступная.
- В подсказках Vanilla и Immortals больше не показывается авторство Arcane Wars.

Это исправления интерфейса. Переустанавливать моды или игровой патч не требуется.

---

# English

- Hovering over a profile avatar no longer draws its outline over the status dot. Closing the avatar preview clears the outline when the pointer is elsewhere. Keyboard navigation retains a separate focus indicator.
- Paw's Patch tooltips for Vanilla and Immortals refresh when changing the mod or channel. They use the selected release's documentation even when an older package is cached locally. Explicitly selecting an archived release shows that release's features.
- Current stable and beta tooltips include WASD and arrow-key camera controls and the F allied map marker in the Dvorak profile. Beta tooltips also include faster saved-game transfers to multiplayer lobby participants. That feature is listed as unavailable for incompatible game versions.
- Vanilla and Immortals tooltips no longer include Arcane Wars author credits.

These are interface fixes. Reinstalling mods or the game patch is not required.
