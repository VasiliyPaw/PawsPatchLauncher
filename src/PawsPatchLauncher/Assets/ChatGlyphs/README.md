These 26 PNGs are the original Kohan II chat glyphs, extracted without image
modification from Data.rwd, Fonts/medium/1280. See provenance.json for source entries,
dimensions and SHA-256 hashes. Game artwork belongs to its original owners.

The launcher sends plain-text :ch_*: tokens and renders only this allowlist as
images. No original game's control characters, HTML or RTF are sent. Older
launcher builds display the text tokens. Glyphs are inserted from the picker;
holding Shift keeps it open for multiple selections. Normal editing shortcuts
(select, copy, cut, paste, undo and redo) belong to the chat editor.
