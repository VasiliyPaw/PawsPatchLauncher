# Paw’s Patch mixed biomes — release integration

Arcane Wars **0.5.0-beta.1** includes mixed biomes, shared building settings, minimap colors, the large-map company cap and UI fixes in the core patch. There is no separate launcher component. Map-type selection remains available in the game.

`tools/PrepareArcane042And050.py` prepares the stable 0.4.2 promotion and this beta independently. Production helper metadata records the new revisions; public archives use six localized main text tables. Cursed land minimap colors use a muted purple hue; terrain textures and gameplay properties are retained.

Release preparation and verification artifacts: `outputs/release-042-050-20261106`. The following notes preserve the independently tested local r2 prototype and its reproduction paths.

## Что изменено

- Новый вариант карты «Смешанные биомы (тест)». Лето, зима, пустыня и проклятые земли образуют крупные области с извилистыми границами. Случайные 5–7 центров распределены по всей карте, первый — внутри неё; одинаковые соседние биомы могут сливаться. Малые оторванные участки меньше 1% площади присоединяются к соседям. Положение, число и формы областей зависят от штатного зерна генерации. Размеры — штатные расширенные 384–2048; в r2 в игре проверены две генерации 1280, а код геометрии — до 2048. Проверки прежней r1 на 384 сохранены отдельно.
- Нативный этап рельефа выполняется один раз. До размещения объектов его клетки переводятся в соответствующие настоящие виды местности. Нативные столкновения, высоты, ограничения размещения, декорации и сохранение сохраняются.
- Для нового составного биома объединены разрешённые переходы, водные параметры и веса декораций исходных четырёх биомов. Приоритеты отрисовки разведены без изменения порядка внутри исходных климатов.
- Настройки строений общие для карты: «Логова», «Большие логова» и «Технологии» показаны по одному разу. После рисования количество распределяется пропорционально фактическим площадям биомов; варианты берутся из исходных климатических групп Arcane Wars. Ноль отключает соответствующую категорию во всех четырёх биомах. Остальные исходные категории (включая отдельную Arcane Wars Tech) также остаются общими. Скрытые настройки животных не добавляют ползунков для биомов.
- Фильтр 89 климатических вариантов проверяет **окончательное** положение после штатного поиска/привязки точки. Никакие штатные проверки не обходятся. Общие объекты остаются общими; некоторые виды исходный мод разрешает сразу в нескольких климатах.
- Потолок ресурса `unit_limit_provided` становится 25, когда обе физические стороны текущего мира не меньше 1200. На доступных квадратных размерах это 1280 и выше. Это потолок, а не бесплатное содержание дополнительных рот. Предел очков построек (`kingdom_points_provided`) и остальные ресурсы не меняются.
- В пользовательских командах числа идут 0, 1, 2… вместо 0, 1, 10… Основной список вариантов команд также сравнивает числовые части как числа; параметры вариантов не переписываются.
- Во время матча по центру экрана расположены меню паузы и реальные окна сохранения/загрузки `StagingFileSavedDialog` / `StagingFileLoadSavedDialog`. В лобби остаётся штатная раскладка.

«Случайно» по-прежнему выбирает один из четырёх исходных климатов: его нативный список ID не расширялся. Смешанные биомы — отдельный пункт.

## Как посмотреть

1. Закрыть обычную Kohan II, оставить Steam запущенным.
2. Запустить `G:\PawMixedBiomesTest-20261106\Смешанные биомы — тест.exe`.
3. Single Player → Custom. Для готовой карты нажать значок дискеты, выбрать `Mixed-R2-1280`, затем Load и Launch. Старые `Mixed-1280` и `Mixed-384` сохранены как примеры прежней раскладки r1.
4. Для новой карты нажать первый значок карты в лобби и выбрать «Смешанные биомы (тест)». При желании поменять размер, плотности и туман войны.
5. В матче Escape открывает меню паузы; Save — исправленное окно сохранения.

Основное меню этой копии английское, новые пункты и подписи биомов русские.
Сохранения и настройки находятся только в `G:\PawMixedBiomesTest-20261106\Documents\Kohan2\data`.
Тестовые сохранения следует открывать в этой копии с её определениями биома и совместимым помощником.

Для максимальных размеров 1536–2048 есть проверки кода и данных, но живое создание в r2 не проверялось.

## Повторение

Ничего из следующих действий не публикует обновление и не пишет в установленную игру.

1. Закрыть запущенную тестовую копию. Python: `C:\Users\Paw\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`.
2. Из корня проекта выполнить `outputs/mixed-biomes-20261106/research.py extract`, чтобы восстановить читаемый снимок определений из исходной QA-копии `G:\PawMoraleBetaQA-20261106\game`. Существующий снимок сохранён в `outputs/mixed-biomes-20261106/definitions`.
3. Выполнить `work/launcher-104-release/game/mixed-biomes/prepare.py`, затем `build.py`. Создание/повторная подготовка ограничены отдельной папкой с точным тестовым маркером.
4. Выполнить сначала `test_geometry.py` (создаёт эталоны разметки), затем `test_native.py`, `test_transactions.py`, `test_ui.py` в той же папке исходников. Базовые проверки — `outputs/mixed-biomes-r2-20261106/test_baseline.py`.
5. `build.json` содержит точные аргументы C#, адреса, исходные байты и поправки адресов. `native/biomes.dll`, `payload.bin`, `payload.json`, `spawn-index.h` и снимок собранных C# сохранены отдельно.
6. Для инструментированной проверки используется `outputs/mixed-biomes-r2-20261106/live.py`; он проверяет путь собственного игрового процесса перед чтением/остановкой. Ручной запуск использует отдельный `TestLauncher.cs` и не включает автоматические игровые команды.

Компилятор нативной части — сохранённый TinyCC i386 0.9.27, без импортов DLL; необходимые функции преобразования чисел статически взяты из `libtcc1-32.a`. Старые прототипы `launcher-081/game/map-shapes` использованы как исследовательская опора и не изменены.

Это частично восстановленные поля, проверенные конкретными путями кода и тестами, а не восстановленные целиком классы движка. Полный проект декомпилятора остаётся в `work/kohan-ii-decompilation`.
